# **App Name**: Character Chronicle

## Core Features:

- Character Sheet: Character Sheet: Digital character sheet to store character stats, skills, equipment, and background information.
- Level Up Prompt: Level Up Prompt: Suggest level up options based on the character's class and current level. Only uses the 2014 5e ruleset.
- Backstory Generator: Character Backstory Generator: Generate a character backstory based on the character's race, class, and alignment using a LLM tool.

## Style Guidelines:

- Primary color: Deep blues and grays to evoke a sense of fantasy and adventure.
- Secondary color: Parchment or aged paper textures for backgrounds and panels.
- Accent: Gold (#FFD700) for highlights, borders, and interactive elements.
- Use clear, readable fonts for character stats and information.
- Fantasy-themed icons for skills, abilities, and equipment.
- Well-organized layout for easy navigation and access to character information.
